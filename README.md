<h1 align="center">Light Field Viewer — 光场图像查看器</h1>

<p align="center">
  <b>版本 V1.1.2</b> · 2026-10-24 · <a href="CHANGELOG.md">更新日志</a>
</p>

用于光场图像/视频的**局部放大对比**、**EPI（极平面图像）提取**和**残差分析**的桌面 GUI 工具。

以下截图和使用说明对应 V1.1.2，包含帧 ID 对齐、等比显示、固定方法图组、视觉对齐、加长的共享色标、数据校验与独立导出批次。

![界面总览](docs/images/overview.png)

## ✨ 功能概览

- 🖼️ **双可视化模式**：支持子孔径图像 (SAI) 和微透镜图像 (MLI) 两种可视化模式
- 📐 **多方法并排对比**：同时显示所有方法的重建结果，支持自适应网格排布
- 🎞️ **视频帧对齐**：默认按帧 ID / 名称匹配，缺帧明确提示；保留按位置兼容模式
- 🗂️ **三个标签页**：SAI/MLI 全图 / 局部放大 / EPI 对比（EPI 仅 SAI 模式可用）
- 🔍 **SAI 全图**：滚轮同步缩放、鼠标拖拽平移、右键拖拽画框
- 🔢 **零填充文件名支持**：兼容 `1_1.png` 和 `013_013.png` 等命名方式
- 🟥 **多矩形框**：支持多个放大区域，颜色自动分配，也可用色板按钮手动指定
- 📊 **残差图**：图像归一化到 `[0, 1]` 后与 Ground_Truth 做差，jet 伪彩色显示，带全局统一颜色条
- 📈 **EPI 提取**：水平/垂直方向，指定角度索引和空间位置，裁剪范围可调
- 💾 **导出功能**：独立批次保存原始图、标注图、局部放大、残差图、EPI，附来源清单与参数日志
- 🌓 **浅色 / 深色外观**：可跟随 Windows 系统设置自动切换，选择会被记住

## 🚀 安装与运行

### 方式一：直接双击 exe 运行（Windows）

无需安装 Python 环境，从 [V1.1.2 Release](https://github.com/chenzean/Light_Field_Viewer/releases/tag/v1.1.2) 下载 `LightFieldViewer.exe`，双击即可使用。

Release 同时提供 `SHA256SUMS.txt` 与 `build-verification.json`，用于核对文件完整性和查看验证范围。旧版 V1.1.1 不包含本次优化。

### 方式二：Python 源码运行

需要 **Python 3.7+**，以及：

```bash
pip install PyQt5 numpy Pillow matplotlib
```

```bash
python main.py
```

| 依赖 | 用途 |
|------|------|
| PyQt5 | 界面 |
| NumPy | 残差与 EPI 计算 |
| Pillow | 图像读写 |
| Matplotlib | 残差图颜色条渲染 |

### 方式三：打包为 exe

```bash
build.bat
# 生成 dist\LightFieldViewer.exe
```

当前打包脚本固定使用 `D:\Anaconda3\envs\LFVFI\python.exe`。如果本机环境路径不同，需要先修改 `build.bat` 中的 `PYTHON_EXE`。

仓库已包含 `LightFieldViewer.spec`，会打包 `assets/` 与应用图标，并优先收集当前 Conda 环境中的 `libexpat.dll`、`libcrypto-3-x64.dll`、`libssl-3-x64.dll`，避免误用其他软件目录里的同名 DLL。`build.bat` 会先安装 PyInstaller 和 PyQt5，再执行构建。

### 回归验证

在已安装依赖的环境中，从项目根目录运行。Windows 原生 Qt 检查使用：

```powershell

```

首次启动时画布是空的：

![空状态](docs/images/empty-state.png)

三种打开方式，效果相同：

- 画布中央的 `打开数据目录…`
- 工具栏的 `打开数据…`（`Ctrl+O`）

如果当前目录没有可用场景，画布上方会提示检查目录层级及 SAI/MLI、图像/视频模式。缺少某方法的当前帧或视角时会清除旧图并提示，不会继续显示上一帧。`刷新` / `F5` 会重新扫描目录并清除图像缓存，保留仍有效的场景、帧和方法选择。

## 3️⃣ SAI / MLI 全图

所有勾选的方法并排显示，网格列数随窗口大小自动调整。缩放和平移在所有方法之间**同步**，
所以放大到同一处细节时可以直接横向比较。

图像始终保持纵横比，默认完整显示在图块内。以有效的 Ground_Truth（不可用时为首个有效方法）的尺寸建立同步坐标，尺寸不兼容的方法明确提示，避免拉伸比较。留白区域不能起画选区。

| 操作 | 按键 / 鼠标 | 说明 |
|------|------------|------|
| 放大 | **滚轮向上** | 以图像内鼠标位置为中心，1.25× 步进，最大 20× |
| 缩小 | **滚轮向下** | 等比缩小，最小回到 1× 全图 |
| 平移 | **左键拖拽** | 放大后拖动查看区域 |
| 平移 | **↑ ↓ ← →** | 键盘微调（需先点一下图像区域取得焦点） |
| 画框 | **右键拖拽** | 直接在图上拖出矩形框，自动加入侧栏列表 |
| 复位 | **双击** 或 **Home** | 回到无缩放无平移 |

画布底部一行灰字会随当前标签页提示可用操作。

## 4️⃣ 侧栏「标注」页

![标注页](docs/images/sidebar-annotate.png)

### 🟥 矩形框

- `添加` 新建一个框，或直接在全图上**右键拖拽**
- 每个框自动分配颜色（红 → 绿 → 蓝 → 黄 → 青 → 品红 → 循环）
- 在列表里选中某个框后，下方的 `位置` / `大小` / `线宽` / `颜色` 作用于该框
- `颜色` 是色板按钮，点开是系统取色器；`删除` 移除选中框，`清空` 移除全部
- SAI 和 MLI 模式都可以用矩形框做局部放大

### 📊 残差图

勾选 `显示残差图 (与 Ground_Truth 对比)` 后，「局部放大」页会在各方法的局部图下方显示对应残差。

- 计算前先把像素除以 `255.0` 归一化到 `[0, 1]`
- 残差为 `mean(abs(method − Ground_Truth), axis=RGB)`，取值范围 `[0, 1]`
- 用 **jet 伪彩色**渲染，越暖（红）差异越大
- 颜色条**全局统一**，范围 `0 ~ global_vmax`；`global_vmax` 取当前帧、当前视角下所有已选非 GT 方法的**全图最大残差**，所有方法和选区使用同一颜色映射，适用于 SAI 和 MLI 模式
- 选区外的残差也参与最大值计算；移动或调整选区不会改变色标，切换方法、帧或视角时色标可能变化
- UI 与导出均先生成全图伪彩色残差，再按选区扩展裁剪并添加边框，保证原始残差图的颜色、尺寸和内容一致（UI 中的显示大小随窗口缩放）
- **需要数据中存在并选中名为 `Ground_Truth` 的方法**，否则无法计算
- 输入必须与 Ground_Truth 同尺寸；尺寸不符时提示原因并跳过该方法的残差，其他有效方法继续显示和导出。

### 📈 EPI 设置（仅 SAI 模式）

勾选 `显示 EPI` 启用，然后：

| 参数 | 说明 |
|------|------|
| **方向** | `水平` / `垂直` |
| **角度索引** | 用第几行/列视角提取 EPI（从 1 开始） |
| **空间位置** | 在图像的第几行（水平）或第几列（垂直）取样，像素索引从 0 开始 |
| **裁剪起始 / 结束** | 半开区间 `[起始, 结束)`；要求 `0 ≤ 起始 < 结束 ≤ 空间长度`，非法范围明确报错 |
| **高度拉伸** | 纵向放大 EPI，便于观察线性结构（`1` = 不拉伸） |

启用后，SAI 全图上会用**蓝色短线段**标出取样位置（只画在裁剪范围内）。

蓝线表示请求的采样位置；实际 EPI 生成失败会另行提示。缺失视角或视角尺寸不一致时不会补黑图参与 EPI。

## 6️⃣ EPI 对比

![EPI 对比](docs/images/tab-epi.png)

所有方法的 EPI 上下排列，名称列保持固定宽度，图像左端对齐，方便逐行比较线性结构的连续性。

缺图时显示占位提示，其宽度也随窗口调整。
如果这一页是空的，回到侧栏 `标注` 页确认 `显示 EPI` 已勾选。

## 7️⃣ 导出

![导出页](docs/images/sidebar-export.png)

1. 侧栏 `导出` 页 → `保存位置` → `浏览…` 选好目录
2. 点工具栏右上角的 `导出结果`
3. 状态栏会显示导出的图片数量和目标路径

`颜色条 DPI` 只影响残差颜色条图片的分辨率，默认 150。

每次导出在选定目录下创建独立的 `export_时间_批次ID/` 子目录，保留旧结果及其色标。坏图、缺图、残差尺寸不符、无效 EPI/选区或写入失败会记录为部分完成或失败，并继续处理其余有效内容。

`manifest.json` 保存完整参数、实际输入路径、帧名、图像尺寸、方法、选区、EPI 参数、残差定义和色标范围、输出清单与错误原因；`export_log.txt` 提供参数与结果摘要。零残差也保存颜色条，并分别记录真实的 `vmax` 与绘图使用的显示上限。已有脚本若读取固定导出路径，需要改为读取对应批次子目录。

### 导出目录结构（SAI 模式）

```
导出目录/export_时间_批次ID/
├── 00_original_sai/           # 原始无标注的 SAI 图
│   ├── Ground_Truth/
│   │   └── Ground_Truth_Scene_f0_3_3.png
│   └── ...
├── 01_rect_annotated/         # 带矩形框 + EPI 标记线的 SAI
├── 02_zoom_crop/              # 局部放大裁剪（带对应颜色边框）
├── 03_epi_full/               # 完整 EPI
├── 04_epi_crop/               # 裁剪后的局部 EPI
├── 05_residual_annotated/     # 全图残差 + 矩形框（jet 伪彩色）
│   └── colorbar.png           # 独立颜色条，范围 0 ~ global_vmax
├── 06_residual_crop/          # 局部残差裁剪（jet 伪彩色 + 边框）
├── manifest.json              # 来源、色标、成功文件与失败原因
└── export_log.txt             # 参数与结果摘要
```

### 导出目录结构（MLI 模式）

```
导出目录/export_时间_批次ID/
├── 00_original_mli/           # 原始无标注的 MLI 图
├── 01_rect_annotated_mli/     # 带矩形框的 MLI
├── 02_zoom_crop/              # 局部放大裁剪（带对应颜色边框）
├── 05_residual_annotated/     # 全图残差 + 矩形框（jet 伪彩色）
│   └── colorbar.png
├── 06_residual_crop/          # 局部残差裁剪（jet 伪彩色 + 边框）
├── manifest.json              # 来源和输出清单
└── export_log.txt             # 参数与结果摘要
```

文件名格式：

- SAI：`方法名_场景_f帧索引_u_v[_后缀].png`
- MLI：`方法名_场景_f帧索引_mli[_后缀].png`

文件名中的帧索引从 0 开始，表示当前统一帧列表的位置；实际来源帧名和路径以 `manifest.json` 为准。

#### SAI 子孔径图像命名

以下命名方式均可正确识别，u 和 v 从 1 开始：

| 命名格式 | 示例 | 说明 |
|----------|------|------|
| `{u}_{v}.ext` | `1_1.png`, `3_5.jpg` | 基本格式，无零填充 |
| `{0u}_{0v}.ext` | `01_01.png`, `03_05.png` | 两位零填充 |
| `{00u}_{00v}.ext` | `001_001.png`, `013_013.png` | 三位零填充 |
| 任意位数零填充 | `0001_0001.png` | 均可正确解析 |

> 同一目录下的所有 SAI 文件应使用相同的命名格式。程序会自动解析数字部分，零填充不影响识别。

#### MLI 微透镜图像命名

| 命名格式 | 示例 | 说明 |
|----------|------|------|
| `{场景名}.ext` | `Bikes.png`, `Fountain.jpg` | 直接放在方法目录下，文件名为场景名 |
